# Changelog

Все значимые изменения в проекте будут задокументированы здесь.

Формат основан на [Keep a Changelog](https://keepachangelog.com/).

## [Unreleased]

### Added
- Полноценная поддержка хранения данных в MySQL/MariaDB через PDO (переключение драйвера через `STORAGE_DRIVER=database`).
- Система аутентификации пользователей: регистрация, вход, выход и просмотр профиля.
- Загрузка и безопасное хранение пользовательских аватаров с валидацией MIME-типов и генерацией уникальных имён файлов.
- Система миграций базы данных (`run_migrations.php`) для управления схемой БД.
- Механизм хранения и валидации CSRF-токенов в сессиях для защиты форм.

### Changed
- Унифицирована структура JSON-файлов для событий (`events`), новостей (`news`) и таймлайна (`timeline`): приведены к единым ключам (`date`, `type`, `is_active`), обеспечена обратная совместимость при чтении.
- Реорганизована структура проекта для соответствия принципам слоистой архитектуры (чёткое разделение на `Application`, `Domain`, `Http`, `Infrastructure`, `View`).
- Переработана система конфигурации: переменные окружения вынесены в `.env` (`.env.local`, `.env.production`), флаги фич (например, `DB_IS_ACTIVE`) вынесены в `.settings.config`.
- Реализован `RepositoryFactory` для прозрачного переключения между JSON и Database-репозиториями без изменения бизнес-логики.

### Security
- Добавлена базовая CSRF-защита для форм входа, регистрации и загрузки аватаров.
- Усилены HTTP-заголовки безопасности: `Content-Security-Policy`, `X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy`.
- Реализована строгая валидация загружаемых файлов аватаров через `finfo` (проверка реального MIME-типа, а не расширения) и защита от Directory Traversal.
- Внедрена функция `sanitizeHtml()` для безопасного вывода пользовательского контента с использованием белого списка разрешённых HTML-тегов и строгой валидации атрибутов `href`.
- Сессии настроены с флагами `httponly`, `samesite=Strict` и регенерацией ID при успешном входе.

### Fixed
- Устранена потенциальная уязвимость при обработке путей к файлам (использование `basename` и `realpath` для проверки границ директории).
- Исправлены ошибки парсинга JSON при некорректной структуре файлов (добавлена обработка `json_last_error`).

- Первый релиз.
- Базовая архитектура: DI-контейнер, роутер, репозитории, локализация.
