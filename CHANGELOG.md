## [Unreleased]

### Added

- Полноценная поддержка хранения данных в MySQL/MariaDB через PDO (переключение драйвера через `STORAGE_DRIVER=database`).
- Система аутентификации пользователей: регистрация, вход, выход и просмотр профиля.
- Загрузка и безопасное хранение пользовательских аватаров с валидацией MIME-типов и генерацией уникальных имён файлов.
- Система миграций базы данных (`bin/run_migrations.php`) для управления схемой БД.
- Механизм хранения и валидации CSRF-токенов в сессиях для защиты форм.
- Новый функционал «Живая книга»: публичная лента откликов, история конкретного экземпляра книги, форма добавления отклика, загрузка фото и AJAX-эндпоинты для графа и деталей книги.
- Доменные сущности и репозиторий для Живой книги: `BookEntity`, `BookEntryEntity`, `BookRepositoryInterface`, `DatabaseBookRepository`.
- Сервис `LivingBookService` для валидации откликов, ограничения «один пользователь — одна запись», подготовки данных графа и получения истории книги.
- Контроллер `LivingBookController` и шаблон `includes/page_living_book.php`.
- Сервис `BookPhotoUploadService` и защищённый выдающий скрипт `public_html/public/get_book_photo.php` для фото Живой книги.
- Сервис `FlashMessageService` для передачи success/error сообщений и old input между redirect-запросами.
- Локализация интерфейса Живой книги для RU/EN.
- Миграции для таблиц контента, виджетов, событий, новостей, таймлайна, Telegram, соцсетей, книг и откликов.
- Database-репозитории для контента и сайдбар-виджетов: events, news, timeline, telegram, social links.
- Абстрактный `AbstractDatabaseItemsRepository` для единой работы с табличными виджетами.
- PHPUnit 10.5 как dev-зависимость, конфигурация `phpunit.xml.dist` и тесты для `ConfigLoader::resolveDatabaseIsActive()`.
- JavaScript-обновление CAPTCHA без перезагрузки страницы: `public_html/scripts/captcha.js`.
- Поддержка реальных URL соцсетей в сайдбаре с `target="_blank"` и `rel="noopener noreferrer"`.
- Мобильные стили layout: скрытие боковых панелей на экранах до 600px.
- Кэширование Composer-зависимостей в GitHub Actions.
- Проверка наличия папки `migrations` и критичных файлов перед деплоем.
- Динамический каталог книг: список книг на `?page=books` и чтение по `?page=books&book=<slug>&action=read`.
- Доменные сущности каталога книг в `src/Domain/Books/`: `BookSummary`, `BookReader`, `BookChapter`, `BookFormat`, `BookRepositoryInterface`.
- Файловый репозиторий `FileBookRepository` в `src/Infrastructure/Books/` с чтением манифестов `book.json` и markdown-глав через CommonMark.
- Конфигурация каталога книг `config/books.php`: включение, порядок, папка книги, форматы скачивания, флаг `featured`.
- Метаданные книги в `book.json`: `title`, `description`, `author`, `language`, `updated_at`, `cover_url`; `title` и `description` поддерживают локализацию объектом `{"ru": ..., "en": ...}`.
- Стабильные HTML-якоря глав на основе `chapter.id` из `book.json` с fallback на `chapter-N` и защитой от коллизий id.
- Шаблон `includes/page_books.php` разделён на три режима: список книг, чтение книги, 404.
- Стили каталога и ридера книг в `public_html/styles/books.css`: карточки с фиксированной обложкой, ограниченной шириной ридера `72ch`, оглавление в рамке, адаптив для мобильных.
- Регистрация `catalog_book_repository` как singleton в контейнере (отдельно от `book_repository` «Живой Книги»).
- Проверка разрешённых хостов (Host header validation) в `bootstrap.php` для защиты от reverse-proxy клонирования сайта.
- Canonical URL теги в `layout.php` для указания оригинального домена `projecthumanity.space` и предотвращения SEO-паразитирования.

### Changed

- Унифицирована структура JSON-файлов для событий, новостей и таймлайна: приведены к единым ключам `date`, `year`, `type`, `is_active`, обеспечена обратная совместимость при чтении старых форматов.
- Реорганизована структура проекта для соответствия принципам слоистой архитектуры: `Application`, `Domain`, `Http`, `Infrastructure`, `View`.
- Переработана система конфигурации: переменные окружения вынесены в `.env`, флаги фич вынесены в `.settings.config`.
- Реализован `RepositoryFactory` для прозрачного переключения между JSON и Database-репозиториями без изменения бизнес-логики.
- Сайдбар-виджеты теперь зависят от интерфейсов репозиториев, а не от конкретных JSON-классов.
- `ContentManager` считает события за активные начиная с сегодняшнего дня, архивные события — строго прошедшие.
- Ограничение `max_items` для виджетов применяется до рендеринга.
- `SimpleContainer` теперь запрещает повторную регистрацию singleton-сервиса.
- Загрузка `config.php` в контейнере стала абсолютной относительно файла контейнера.
- Если выбран драйвер `database`, но БД не активна, система автоматически переключается на `json`.
- Флаг `DB_IS_ACTIVE` теперь корректно читается из настроек и приводит строковые значения `true/false/on/off/1/0` к boolean.
- Session cookie `secure` теперь корректно определяется с учётом `HTTPS`, `X-Forwarded-Proto` и порта 443.
- Регенерация session ID перенесена из глобального bootstrap в момент успешного входа пользователя.
- Обработчик ошибок поддерживает отдельные статусы 404 и 500, nullable параметры файла/строки/трейса и более безопасный вывод.
- Форма авторизации полностью экранирует выводимые значения через `htmlspecialchars(..., ENT_QUOTES, 'UTF-8')`.
- CAPTCHA отдаётся с заголовками `no-store`, `no-cache`, `must-revalidate`.
- Деплой-workflow упрощён: убраны pull-request-логика и dry-run rsync, оставлен деплой только из `master` и ручного запуска.
- Rsync теперь исключает только корневые `/vendor/`, `/node_modules/`, `/storage/`, `/logs/`, что позволяет деплоить локальные статические ассеты из `public_html/vendor/`.
- Composer install на сервере запускается с `--prefer-dist`.
- Обновлены стили виджетов новостей и событий.
- Увеличена ширина левого сайдбара до 25%.
- Раздел «Книги» переведён с жёстко зашитой одной книги (`BOOK_DIR = .../project-humanity`) на динамический каталог с множеством книг.
- `BooksController` больше не читает файловую систему напрямую: работа с манифестами и главами вынесена в `FileBookRepository`.
- `BooksData` расширен полями `books`, `author`, `description`, `coverUrl`, `updatedAt`, `formats`, `message` для поддержки списка, ридера и 404.
- Переключатель языка в `includes/layout.php` сохраняет текущие query-параметры (включая `book` и `action`), а не сбрасывает их до `?page=<page>&lang=<lang>`.
- `includes/layout.php` экранирует `$page`, `$lang_code`, `$site_title`, `$page_title`, `$description`, `$version` через `htmlspecialchars(..., ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8')`.
- `bootstrap.php` теперь блокирует запросы с неразрешёнными хостами на уровне PHP (403 Forbidden) с поддержкой whitelist доменов.
- `layout.php` генерирует абсолютные canonical URL с принудительным использованием домена `projecthumanity.space` для борьбы с клонами в поисковых системах.

### Security

- Добавлена базовая CSRF-защита для форм входа, регистрации, загрузки аватаров и Живой книги.
- CSRF-токены хранятся в сессии с TTL 1 час и сравниваются через `hash_equals()`.
- Усилены HTTP-заголовки безопасности: `Content-Security-Policy`, `X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy`.
- Реализована строгая валидация загружаемых файлов аватаров через `finfo` и защита от Directory Traversal.
- Фото Живой книги хранятся вне публичной директории и выдаются через контроллер с проверкой `realpath`, MIME-типа `image/jpeg` и строгого формата имени файла.
- Внедрена функция `sanitizeHtml()` для безопасного вывода пользовательского контента с использованием белого списка разрешённых HTML-тегов и строгой валидации атрибутов `href`.
- Ссылки соцсетей открываются с `rel="noopener noreferrer"`.
- Slug книги валидируется по whitelist-регулярке `^[a-z0-9][a-z0-9_-]{0,63}$` (регистронезависимо) перед обращением к файловой системе.
- Защита от directory traversal при резолвинге папки книги и путей глав: `realpath()` + проверка `str_starts_with($resolved, $baseDir . DIRECTORY_SEPARATOR)`.
- Нормализация публичных URL (обложки, форматы скачивания): допускаются только `/...` и `http(s)://...`; отклоняются `javascript:`, `data:`, protocol-relative `//`.
- Markdown-конвертер CommonMark для глав и оглавления настроен с `html_input=strip` и `allow_unsafe_links=false`.
- **Добавлена защита от клонирования сайта через reverse proxy** (foodinnovation.ru и подобные домены): реализована валидация HTTP_HOST с whitelist разрешённых доменов (`projecthumanity.space`, `www.projecthumanity.space`, `localhost`), запросы с другими хостами блокируются с кодом 403.

- Исправлены ошибки парсинга JSON при некорректной структуре файлов, добавлена обработка `json_last_error()`.
- Исправлен путь к favicon: вместо `/public_html/favicon.ico` теперь `/favicon.ico`.
- Исправлен путь к CAPTCHA в форме авторизации.
- Исправлено кэширование CAPTCHA в браузере.
- Исправлена нормализация событий, новостей и таймлайна для единообразных ключей.
- Исправлена фильтрация неактивных элементов в JSON-репозиториях.
- Исправлено поведение `ContentManager` при отсутствующих или некорректных датах.
- Исправлена передача `DEPLOY_PATH` в remote-скрипт post-deploy задач.
- Добавлена явная ошибка, если `bin/run_migrations.php` отсутствует на сервере.
- Якоря глав в оглавлении и в секциях `<section class="book-chapter">` теперь стабильны и не сдвигаются при добавлении/удалении/перестановке глав в середине книги.
- Переключение языка на странице чтения книги больше не выбрасывает пользователя обратно в список.
- Корректная обработка портов в проверке хостов: домен с портом (например, `localhost:8080`) корректно разрешается благодаря удалению порта перед проверкой.

- Из CI/CD удалён dry-run rsync.
- Из CI/CD удалён шаг установки Let's Encrypt root certificates.
- Из workflow удалён триггер и логика для pull request.
- Старый URL `?page=books&action=read` (без параметра `book`) больше не работает и отдаёт 404; обратная совместимость не предусмотрена намеренно.
